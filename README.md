# John-Paul-Escuadra

Mono-repository for the John Paul Escuadra project. The frontend and
backend applications live in this repository as tracked directories.

## Repository Structure

- Frontend_JP/ — frontend application
- Backend_JP/ — backend application

## Documentation

- docs/Road_Map.md — canonical project road map (single source of
  truth for phase status)
- HISTORY.md — historical record of completed and superseded phases,
  including the T-01 mono-repo migration

## Provenance

This repository was consolidated on 2026-09-13 by the T-01 migration,
which merged the previously separate Frontend_JP and Backend_JP
repositories into this single repository while preserving their full
commit histories. See HISTORY.md for the complete record.
